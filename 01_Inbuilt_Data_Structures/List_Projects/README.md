# Python List Projects

This folder contains a collection of beginner-friendly Python projects developed to strengthen my understanding of the **List data structure** and its practical applications.

The projects focus on using Python lists to store, modify, search, process, and iterate through data.

## 📌 Projects

### 1. Inventory Management

A simple inventory management program using a Python list to manage items in stock.

**Concepts demonstrated:**

* Creating and modifying lists
* Adding items using `append()`
* Removing items using `remove()`
* Checking item availability using the `in` operator
* Using conditional statements
* Iterating through a list using a `for` loop

The program adds `grapes` to the inventory, removes `banana`, checks whether specific items are available, and displays the remaining inventory.

**File:** `Inventory_Management.ipynb`

---

### 2. Organizing Student Grades

A simple program for storing and analysing student grades using a Python list.

**Concepts demonstrated:**

* Creating a list of grades
* Adding new values using `append()`
* Calculating the average using `sum()` and `len()`
* Finding the highest value using `max()`
* Finding the lowest value using `min()`

The program calculates the average, highest grade, and lowest grade from the stored values.

**File:** `Organizing_Grades.ipynb`

---

### 3. To-Do List

A simple task management program that demonstrates how Python lists can be used to manage a collection of tasks.

**Concepts demonstrated:**

* Creating a list of tasks
* Adding tasks using `append()`
* Removing completed tasks using `remove()`
* Checking whether a task exists using the `in` operator
* Iterating through the remaining tasks using a `for` loop
* Using conditional statements

The program adds new tasks, removes a completed task, checks for a specific task, and displays the remaining to-do items.

**File:** `To_Do_list.ipynb`
